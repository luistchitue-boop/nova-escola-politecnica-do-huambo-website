# Nova Escola Politécnica do Huambo — Landing Page

Projeto Next.js + TailwindCSS: landing page profissional de exemplo para a Nova Escola Politécnica do Huambo. The site uses premium typography (Playfair Display + Inter) and supports a hero image when placed at `public/hero.jpg`.

Instalação e execução:

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

To use a photographic hero, add a high-resolution `hero.jpg` to the `public/` folder. The layout will fall back to a gradient if no image is present.
